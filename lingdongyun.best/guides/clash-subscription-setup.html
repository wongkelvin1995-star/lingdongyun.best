买套餐前先确认：设备、客户端与订阅格式

灵动云套餐选择 · 更新于 2026-11-01

买灵动云套餐之前，先确认三件事：要在哪些设备上用，每台设备装哪个客户端，这个客户端能不能读取灵动云提供的订阅格式和 SS（Shadowsocks）协议。三件事都对上，付款后导入订阅通常几分钟就能完成；没对上，就可能买完才发现手上的软件用不了。本文只讲付款前的核对，安装和导入步骤请看使用指南。

第一步：列出要用的设备

把会用到的设备都写下来：Windows 电脑、Mac、安卓手机、iPhone 或 iPad，顺便记下系统版本。较旧的系统可能装不了新版客户端，最好提前确认。

灵动云套餐不限设备数量，同一个订阅可以导入你所有的设备。但流量是这些设备共用的，设备越多，越要把各自的用量加起来估算，方法见每月流量估算。

如果要在 iPhone 或 iPad 上使用，还要多留意一点：小火箭（Shadowrocket）这类客户端通常需要用非中国大陆地区的 Apple ID 才能在 App Store 下载。手上没有的话，先把这件事解决再付款。

第二步：给每台设备选好客户端

客户端是你看到的软件界面，真正负责连接的是它内置的「内核」。Clash 系列客户端（如 Clash Verge Rev、Clash Party、Clash Meta for Android）使用 Mihomo 内核，读取 Clash（Mihomo）格式的配置；小火箭是独立开发的苹果设备应用，能导入多种订阅格式；v2rayN 和 v2rayNG 则是 Windows 和安卓上另一类常用客户端。

不同设备选哪个客户端，可以先向客服确认。请只从软件的官方渠道或正规应用商店下载，不要用来路不明的安装包。

第三步：确认订阅格式

很多服务都写着「支持 Clash」，但这句话可能有三种意思：

  1. 直接提供 Clash 配置订阅：订阅内容是一份完整的 YAML 配置，包含节点、代理组和规则，导入就能用。
  2. 提供通用订阅：订阅内容只是节点列表，由客户端自己解析。
  3. 只说明协议兼容：节点用的协议客户端能识别，但服务本身未必提供完整的 Clash 配置。

所以「支持某个协议」不等于「一定有现成的 Clash 配置」。灵动云按客户端准备了三种订阅链接：Clash 订阅链接给 Clash Party、Clash Verge Rev、Clash Meta for Android 等 Clash 系列客户端，通用订阅链接给 v2rayN 和 v2rayNG，小火箭订阅链接给小火箭。这三种链接都不是自己挑选的，付款后在用户中心提交工单，说明设备和客户端，客服会发来对应的一条。不确定自己的客户端能不能用，也可以在付款前先向客服问清楚。

注意：不要把订阅链接交给来历不明的在线「订阅转换」网站。转换时要提交你的订阅地址，等于把账号的访问凭证交给了第三方。订阅链接一旦泄露，请尽快在用户中心提交工单处理。

第四步：确认协议和客户端版本

灵动云的节点使用 SS（Shadowsocks）协议。这是一个成熟、通用的协议，上面提到的客户端都支持，一般不会遇到「协议不认识」的问题。只需要注意两点：

  • 不同客户端内置的内核版本不同，太旧的版本可能不支持较新的加密方式，尽量使用仍在维护的版本；
  • 协议决定的是「能不能连上」，不决定「快不快、稳不稳」，后者要看线路和实际使用情况。

两个容易忽略的问题

设备上已经装了别的代理软件

只要现有客户端支持 SS 协议，又能导入上面三种订阅链接中的一种，就可以直接在里面新增一个订阅，不必重装；拿不准的话，把客户端名称告诉客服问一下。但同一台设备上同时开着多个代理、VPN 或加速器，容易互相抢占系统代理，导入灵动云订阅前先把其他代理软件退出。

公司或学校统一管理的设备

一些单位统一管理的电脑和手机不允许安装软件，或者锁定了系统代理设置。打算在这类设备上使用，先确认自己有安装软件和修改设置的权限，免得付款后才发现装不上。

购买前确认清单

  • 我要在哪些设备上使用，系统版本分别是多少；
  • 每台设备都选好了客户端，知道从哪个官方渠道下载；
  • 如果要在 iPhone / iPad 上用，已经有可用的非中国大陆地区 Apple ID；
  • 客户端支持 SS 协议，也清楚它该配 Clash、通用还是小火箭订阅链接；
  • 估算过所有设备加起来每月大约用多少流量；
  • 知道订阅链接要保密，不发给别人，也不交给在线转换工具；
  • 知道领取订阅链接和遇到问题时找谁：客服，或用户中心工单。

付款之后

付款后，在用户中心提交工单，告诉客服每台设备分别用什么客户端，领到对应的订阅链接后按设备导入。导入后连不上，可以先检查订阅链接是否完整、系统时间是否准确、客户端是否为最新版本，仍不能解决再提交工单。
